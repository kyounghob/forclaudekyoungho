학습 설계

학습자 조건을 직접 입력하거나 자연어로 초안을 만든 뒤 추천을 계산하세요. 모든 추천은 미리 학습된 모델 번들로 계산하며 요청 중 재학습은 없습니다.

      1. 학습자 아이디어 스케치

      예시 문장을 넣거나 자연어로 학습자를 설명하세요. 읽어 낸 조건은 아래 입력칸에서 다시 확인할 수 있습니다.

      이렇게 적어보세요

      ① 관심 주제 → ② 수준(초급·중급·고급) → ③ 투자 경험·위험성향 → ④ 기기·시간대 → ⑤ 개수 순서로 적으면 됩니다. 따옴표 안에 단원 제목을 적고 "통과"·"완료"를 붙이면 학습 기록으로 읽습니다. 적지 않은 항목은 기본값을 씁니다.

      예시: "ETF 구조와 비용에 관심 있는 초급 학습자야. 투자 경험은 없고 모바일로 저녁에 공부해. 5개 추천해 줘."

      외부 API 없이 규칙으로 읽습니다. 읽어 낸 값은 2~4단계에서 수정할 수 있습니다.

      읽어 낸 조건

      2. 기본 정보

      연령대·소득분위는 세그먼트 변수로 쓰고, 성별은 수집하되 운영 라우터에서 제외합니다. 비워 두면 기본값을 씁니다.

      3. 관심 주제와 수준

      관심 주제는 최대 2개입니다. 수준은 모의 진단 값이며 학습 기록이 쌓이면 퀴즈 결과로 갱신됩니다.

      진단 수준

      간단 진단 3문항으로 수준 정하기 (선택)

      4. 학습 기록

      학습 시도마다 한 행입니다. 조회 1·완료 2·퀴즈 통과·저장 3점의 최댓값이 행동 점수가 되고, 퀴즈 통과 단원은 추천 후보에서 빠집니다. 이탈은 비선호로 보지 않습니다.

      CSV로 불러오기 (item 또는 title, complete, quiz_pass, save, drop 열)

      5. 추천 설정

      기본값은 검증에서 고른 운영 설정입니다. 비교 목적이면 다른 기법을 강제로 고를 수 있습니다.

      6. 추천 미리보기

      아직 계산하지 않았습니다.
      보기 배율 100% 주제 × 수준 배치도 · 열 = 주제 20개, 행 = 수준 3단계
