학습 설계

학습자의 투자 목적·성향·지식 수준을 진단하고 → 필수 기초 개념부터 목적별 핵심·심화 개념까지의 로드맵을 만든 뒤 → 다음에 공부할 단원을 추천하고 → 적합한 ETF 유형으로 연결합니다. 모든 계산은 미리 학습된 모델 번들로 하며 요청 중 재학습은 없습니다. 특정 상품의 매수·매도를 권유하지 않습니다.

      1. 학습자 아이디어 스케치

      예시 문장을 넣거나 자연어로 학습자를 설명하세요. 읽어 낸 조건은 아래 입력칸에서 다시 확인할 수 있습니다.

      이렇게 적어보세요

      ① 투자 목적(연금·노후, 배당·인컴, 장기 지수 투자, 단기 매매, 분산·안정) → ② 관심 주제 → ③ 수준(초급·중급·고급) → ④ 투자 경험·위험성향·투자 기간 → ⑤ 기기·시간대 → ⑥ 개수 순서로 적으면 됩니다. 따옴표 안에 단원 제목을 적고 "통과"·"완료"를 붙이면 학습 기록으로 읽습니다. 적지 않은 항목은 기본값을 씁니다.

      예시: "45세 직장인, 연금저축과 IRP로 노후 준비. 투자 경험 1~3년, 안정 성향, 10년 이상 장기로 모바일 저녁 학습. 초급."

      외부 API 없이 규칙으로 읽습니다. 읽어 낸 값은 2~4단계에서 수정할 수 있습니다.

      읽어 낸 조건

      2. 기본 정보와 투자 목적

      투자 목적·투자 기간·위험성향은 로드맵의 단계 구성과 ETF 유형 연결에 쓰입니다. 연령대·소득분위는 세그먼트 변수로 쓰고, 성별은 수집하되 운영 라우터에서 제외합니다. 비워 두면 기본값을 씁니다.

      투자 목적과 기간

      3. 진단: 관심 주제·수준·진단 퀴즈

      관심 주제는 최대 2개입니다. 수준은 직접 고르거나 진단 퀴즈로 정합니다. 맞힌 문항의 단원은 '진단 통과' 기록이 되어 추천 후보에서 빠지고, 틀린 문항은 기록하지 않습니다.

      진단 수준

      진단 퀴즈

      4. 학습 기록

      학습 시도마다 한 행입니다. 조회 1·완료 2·퀴즈 통과·저장 3점의 최댓값이 행동 점수가 되고, 퀴즈 통과 단원(진단 통과 포함)은 추천 후보에서 빠집니다. 이탈은 비선호로 보지 않습니다.

      CSV로 불러오기 (item 또는 title, complete, quiz_pass, save, drop 열)

      5. 학습 로드맵

      진단 → 필수 기초 개념 → 목적별 핵심 개념 → 심화·리스크 → ETF 유형 연결. 각 단원은 선수 단원을 통과해야 열립니다. 추천 엔진은 현재 단계의 학습 가능 단원에 가중치(로드맵 신호)를 주고, 가드레일로 선수 미이수 단원을 거릅니다.

              9. ETF 유형 연결과 데이터 출처

              로드맵의 마지막 단계입니다. 목적·성향에 맞는 ETF 유형을 교육용 카드로 보여 주고, 각 유형에 필요한 개념 단원의 통과 여부로 카드가 열립니다. 유형 통계는 KRX 정보데이터시스템 ETF 전종목 기본정보(또는 샘플)에서 계산하며, 개별 상품의 적합성 판단이나 매수 권유가 아닙니다.

              계산 중…

              공개 데이터·교육 자료 출처

              단원 자료와 유형 통계의 출처 목록입니다. 기관 개편으로 세부 주소가 바뀔 수 있어 기관 루트와 메뉴 경로를 함께 표시합니다. '확인'은 2026-10 기준 검색으로 확인한 범위입니다.
